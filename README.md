## Features
- **Executive National Overview**: Real-time headline KPIs (GDP, Inflation, Unemployment, Demographics, Energy).
- **Macroeconomics & International Trade**: Sectoral GDP composition, multi-year export/import trade balances, and top commodities.
- **Population & Demographics**: 5-year age-sex cohort horizontal population pyramid (2026 Census).
- **Labour Market & Regional Workforce**: Regional unemployment rates, workforce participation, and real wage dynamics.
- **Accessible & Responsive Design**: Seamless layout scaling from desktop (1280x800) down to mobile (390x844), dark/light theme, and live CSV data export.

## Architecture
- Static files under `app/` (zero build step, pure ES modules, zero network dependencies).
- Runs offline in desktop and mobile web browsers.
